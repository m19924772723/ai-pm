## 踩坑日志

**1. GitHub SSH 说断就断**
- 现象：push origin 报 "correct access rights"，而 30 分钟前还能推
- 怎么试的：ssh -T 直测 → github.com:22/443 都被 TCP 重置；api.github.com 和 github.com HTTPS 正常
- 结果：`gh auth setup-git` + HTTPS 一次性推送成功；本地 ref 用 update-ref 校正
- **面试可讲**（延伸）：遇到"推不动"先分三层——DNS/连通性（curl）、认证（ssh -T）、历史分叉（git log origin/main）——三层各自一句话定位
