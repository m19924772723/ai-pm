## 踩坑日志

| 问题 | 怎么试的 | 结果 |
|---|---|---|
| 系统代理 127.0.0.1:7892 挂掉（连接被拒绝），GitHub API 查询全失败 | ① 先带代理试 → 连接被拒 ② unset http_proxy/https_proxy 直连 | 直连可用：api.github.com / gh CLI 直连正常，三平台 SSH 也正常。**结论：代理挂了就先 unset 直连，不要误判"平台被封"** |
| Excel 文件被占用（`~$xxx.xlsx` 锁文件 + EXCEL.EXE 进程），脚本写入报 PermissionError | ① 先写临时文件 ② 等用户关闭 Excel 后再覆盖 | 成功。**没有强杀 Excel 进程**（怕丢未保存内容）——这个判断是对的 |
| 生成 xlsx 时两次忘记写表头行，读出来第 1 行全空 | 用 `xlsx_read.py --json` dump 出来核对，发现维度从 A2 开始 | 已修：写表头要在写数据之前调用，且必须验证（不能只看"保存成功"） |
| 每日打卡表里"启动包"阶段还没开项目，显示成"推进：—（打基础，不开项目）" | 加分支：阶段无项目时改用实践线内容 | 已修 |
