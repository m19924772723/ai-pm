# L2 案例① 试用材料（找 3-5 人试用的可直接发版）

> 准备日期：2026-10-15（Day 23）· 当前 L2 未上线，试用走**本机演示 + 引导问答**
> 找真人用的关键：让试用者直接问**他自己的问题**，而不是演示标准答案——否则反馈全是"不错"，没信息量。

## 给试用者的邀请话术（可直接复制）

> 我在做一个"个人知识库问答"小工具（作品集项目）：把你的资料变成可问答的库，答案带原文引用。
> 现在想找 3-5 个人试用 10 分钟，收集真实反馈。你不需要懂技术，就问几个**你自己想知道、但懒得翻文档**的问题就行。
> 反馈三件事：① 有没有问不到（应该资料里有的）② 有没有答错/引用不对 ③ 有没有"答不出"但其实该答的。

## 试用流程（本机演示，10 分钟）

1. 我开个终端跑 `python -m scripts.qa_demo`（4 个演示问答：故障转移/幻觉率/分块偏移/无关拒答）
   —— 先让试用者看到"能答 + 有引用 + 会拒答"三条能力
2. 然后让试用者**自己报 2-3 个问题**（关于工作区资料的，如"L1 的幻觉率是多少"）
3. 每问记 3 个字段：`问题 / 回答质量（1-5） / 引用对不对`

## 反馈收集模板（试用完填 log 用）

```text
试用者：<称呼>（同学/同门）
日期：2026-10-XX
Q1: <问题> → 回答质量 X/5，引用 ✓/✗（<说明>）
Q2: ...
改进建议（原话或转述）：...
```

## 阈值（决定"是否可移交部署"）

- 3 人以上、2/3 说"能用"且无引用错误 → 进部署优先级
- 有人指出"该答的没答" → 记入评测集（这类样本最值钱，转成新 gold）
