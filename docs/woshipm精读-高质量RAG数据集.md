# 精读：AI产品经理：从文档解析到数据清洗，打造高质量RAG数据集

> 来源：[woshipm.com/ai/6266979.html](https://www.woshipm.com/ai/6266979.html) ｜ 作者：产品经理小易
> 精读日期：2026-10-09（Day 17，学习线）｜ 正文 4694 字

## 一、核心论点

**RAG 知识库的质量取决于投入的数据，不取决于框架。** Dify / LangChain / RAGFlow 只是工具；
真正起决定作用的是"制定数据集标准 → 整理解析文档 → 清理结构化数据"三步。

## 二、数据集四大标准

| 标准 | 文章说法 | 我的 L2 现状对照 |
|---|---|---|
| 内容完整性 | 不能漏业务内容，否则答非所问 | ✅ 语料=工作区全部 36 篇真实文档，sha1 指纹防漏 |
| 内容准确性 | 错误信息=毒药，模型对检索结果天然信任 | ⚠️ 文档本身是我自己写的，无外部错源；评测集守幻觉率 |
| **关系完整** | "没有目录的说明书"——标题层级/步骤关系 | ✅ 分块按标题层级切 + heading_path 逐块记录（正好对应） |
| 元数据完整 | 时间/来源/格式/权限/语义标签=隐形目录 | ⚠️ 目前只存 doc_id/source/heading/偏移，**缺时间戳与语义标签** |

## 三、解析逻辑：成本 × 质量 × 速度 三角

- Word：python-docx 抽文本 + 图片导出成 image_map（引用 ID → HTML 标签）→ 图文混排
- PDF：**本质是按坐标绘制、无语义结构** → PyMuPDF 提文字块+坐标 → 版面还原（重建段落/标题）→ 图文同步 → 输出统一 HTML 块
- 音频（会议/播客）最小可行：ASR 转文字+时间戳 → **20-40s 切块、重叠 2-3s、保留 {text,start,end,audio_path} 四元组** → 语义+关键词双索引 → 答案附时间戳跳转可回溯原音频
- 视频：先音轨问答（低成本跑通），再按需加关键帧截图 + OCR（{timestamp, image_path, ocr_text}）

## 四、数据清洗七步（按顺序执行）

1. **格式清理**：去 HTML 标签/页眉页脚/页码/水印、统一换行符
2. **编码与字符标准化**：UTF-8、全角转半角、去零宽空格/BOM
3. **冗余信息过滤**：去版权/广告/重复段、去目录参考文献致谢、**去短于 N 字符的无意义段落**
4. **结构恢复**：恢复标题层级、合并跨页断段、表格/列表/代码块还原为结构化文本
5. **语义连贯性修复**：合并断句、修 OCR 错误、统一术语
6. **语言与分词预处理**：中英文间加空格、统一大小写、按 embedding 模型决定是否分词
7. **分块前准备**：按标题/段落/句子初步切分、保留标题-正文关联（##标题\n正文）、标记特殊块（代码/表格/引用）

## 五、对我 L2 的对照发现（3 条要补）

1. **ASCII 线框图是典型"冗余噪声"**：我实测它污染稠密检索（任何查询都最相关），
   混合检索（BM25 免疫特殊字符）已中和——但按文章第 3 步，正确做法是**分块时剔除/标记纯图块**，而不是靠 BM25 兜底。→ L2 后续候选
2. **元数据缺时间戳与语义标签**：文章说元数据是"隐形目录"。
   我的块只有 doc/source/heading/偏移——补"日期"对"Day 5 完成了什么"这类跨日期问法有直接帮助（10-09 检索评测漏检的那个问题）。
3. **中英文空格/术语统一未做**：我的语料有 "Streamlit Community Cloud" 等混排，
   nemotron-embed 对中英混排弱，统一格式（步骤 6）可能直接提升检索质量。→ 低成本候选（清洗脚本）

## 六、一句话收获

> 分块的关键不是"切多短"，而是**切完还能找得回上下文**（标题层级=目录，偏移=页码，元数据=标签）。
> 我 Day 16 的"标题层级+偏移"做对了前两件事，第三件事（元数据）是下一个增量。

## 自测题

1. 为什么 PDF 的解析难度天然高于 Word/Markdown？（答：PDF 是版面呈现驱动、按坐标绘制、无语义结构；Word/Markdown 是标记文档）
2. 数据清洗七步里，哪一步能直接缓解"ASCII 图块污染检索"？（答：第 3 步冗余过滤——剔除无意义/非正文块）
3. 音频切块为什么要重叠 2-3 秒？（答：避免语义在切点被切断——与文本分块的重叠同理）
4. 元数据补什么字段能改善"Day 5 完成了什么"这类问法？（答：日期/时间戳字段，配合语义标签）
