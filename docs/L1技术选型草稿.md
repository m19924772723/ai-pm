# L1 技术选型草稿（Day 3 产出）

> 项目：L1-1 长文 → 结构化（练手项目）
> 阶段：MVP，目标 2 周内可用
> 原则：能用现成的不自己造，先跑通再优化

---

## 1. 技术栈选择

| 模块 | 选型 | 为什么 |
|---|---|---|
| 前端/UI | Streamlit | Python 原生，30 分钟出原型，不需要前后端分离 |
| 文本提取（网页） | trafilatura | 专为新闻/文章设计，准确率高，API 简单 |
| 文本提取（PDF） | PyMuPDF（fitz） | 支持文本+表格提取，Python 绑定成熟 |
| LLM 调用 | 中转 API（OpenAI 兼容接口） | 个人项目不需要自己跑模型，先用现成接口 |
| Prompt 管理 | 硬编码在代码里 | MVP 阶段不需要 prompt 管理工具，后续再抽离 |
| 数据存储 | JSON 文件 | MVP 够用，后续再换 SQLite/数据库 |
| 评测 | 手工标注 + 简单脚本 | 先人眼看 20 条，再自动化 |

### 实测修正（2026-09-27，Day 5）

| 项 | 草稿原写法 | 实测后 |
|---|---|---|
| 模型端点 | "中转 API（siyu 等）" | **默认 stepfun / step-3.7-flash**；siyu 该 key 返回 403 订阅失效，tuoji 的 deepseek 无可用通道，deepseek 官方可用但需 max_tokens ≥512 |
| 输出预算 | （未写） | **max_tokens 需 ≥8192**：4096 时归档模板 JSON 被截断（推理模型先消耗推理 token） |
| 评测集文件名 | `tests/eval_20.json` | 改为 **`tests/eval_set.json`**：现在只有 4 条，文件名带"20"会误导 |

## 2. 为什么不选其他方案

| 方案 | 为什么不选 |
|---|---|
| FastAPI + 前后端分离 | 启动慢，L1 阶段不需要，Streamlit 足够 |
| LlamaIndex | 学习成本高，先用原生 LangChain 或直接调 API |
| 向量数据库（Chroma/Qdrant） | L1 是"单文档结构化"，不需要检索，先跑通再考虑 |
| Promptfoo/Langfuse | 评测阶段再用，MVP 先人眼检查 |
| 自托管模型（Ollama） | 中转 API 成本低、质量高，个人项目不需要 |

---

## 3. 第一版能做什么 / 不能做什么

### 能做（V0.1）
- [ ] 粘贴文本 → 选择模板（摘要 / 待办 / 归档）→ 一键生成结构化结果
- [ ] 输入网页链接 → 自动抓取正文 → 结构化
- [ ] 上传 PDF → 提取文本 → 结构化
- [ ] 导出结果为 JSON / Markdown

### 不能做（V0.1 明确排除）
- [ ] 多轮对话（一次性输出，不保持上下文）
- [ ] 历史记录（刷新就丢，不存数据库）
- [ ] 用户账号（单机版，不需要登录）
- [ ] 文件批量处理（一次一个）
- [ ] 自定义模板（只有 3 个固定模板）

## 4. 项目结构

```
projects/L1-longtext-struct/
├── app.py                  # Streamlit 主入口
├── pipeline.py             # 核心链路：文本 → 结构化 JSON
├── scripts_probe.py        # 逐个探测 provider 是否可用
├── scripts_verify.py       # 一次真实调用，验证链路
├── run_eval.py             # 跑评测集，算三个指标
├── rescore.py              # 换指标定义后复算（不重跑模型）
├── extractors/
│   ├── web.py              # trafilatura 网页提取 + 兜底规则
│   └── pdf.py              # PyMuPDF PDF 提取
├── prompts/
│   └── templates.py        # 摘要/待办/归档三套模板
├── utils/
│   ├── llm.py              # 模型调用封装（密钥只从环境变量读）
│   └── schema.py           # JSON 提取 + Schema 校验 + 证据回溯
├── data/
│   └── sample_inputs/      # 测试用输入样例
├── tests/
│   ├── eval_set.json       # 评测集（现 4 条，目标 20 条）
│   ├── eval_set_meta.py    # 评测集统计
│   ├── test_schema.py      # 离线单测
│   └── test_eval_matcher.py
├── logs/                   # 评测结果与运行记录
├── requirements.txt
├── .env.example
└── README.md
```

## 6. 风险与止损

| 风险 | 信号 | 应对 |
|---|---|---|
| 中转 API 不稳定 | 连续 3 次调用失败 | 换备用 API / 本地 Ollama |
| 提取准确率低 | trafilatura 提取结果缺段落 | 加回退规则（正则兜底） |
| Prompt 效果差 | 3 次输出格式不对 | 加 JSON Schema / output_format 约束 |
