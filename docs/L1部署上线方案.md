## 1. 为什么用 Streamlit Community Cloud

| 项 | 说明 |
|---|---|
| 成本 | 免费（个人 app 公开可用） |
| 复杂度 | 一键部署，不用买服务器/Docker/K8s |
| 与项目匹配 | L1 本来就是 Streamlit 写的，零改造 |
| 证据价值 | 拿到线上 URL = 面试第 7 问"有没有上线、谁在用"有真实答案 |

> 替代方案（暂不选）：Vercel（要改前端框架）、Railway（要钱/要配置）、自建服务器（运维成本高）。
> L1 是练手项目，用最省事的上线路径；L2/L3 再考虑更重的部署。

## 2. 官方部署步骤（2026-10 核实）

1. 打开 https://share.streamlit.io（用 GitHub 账号登录）
2. 右上角 **Create app** → "Yup, I have an app"
3. 填 **repository**（`m19924772723/ai-pm`）、**branch**（`main`）、**main file path**（`projects/L1-longtext-struct/app.py`）
4. （可选）选 App URL 子域名
5. **Advanced settings**：
   - Python version 选 **3.11**（本地就是 3.11，版本一致最稳）
   - Secrets 框里粘贴密钥内容（格式见下）
6. Deploy，等 2-5 分钟

## 3. 依赖声明（关键，容易踩坑）

- Community Cloud 从**入口文件同目录**或**仓库根目录**找依赖文件，优先级：
  `uv.lock > Pipfile > environment.yml > requirements.txt > pyproject.toml`
- 我们的 `requirements.txt` 就在 `projects/L1-longtext-struct/` 下（与 app.py 同目录）✅
- ⚠️ **`requirements.lock.txt` 不在官方识别列表里，会被忽略**——没关系，云端会用 `requirements.txt`（宽松版本），本地才用 lock 精确复现
- **只在同一处放一个依赖文件**：我们的 `requirements.txt` 在项目子目录、根目录 `ai_pm` 没有 requirements.txt，无冲突 ✅
- 版本必须与本地一致：云端默认 Python 3.12，我们本地 3.11 —— 记得在 Advanced settings 里选 3.11

## 4. 密钥怎么处理（绝不进仓库）

- 本地开发：`.streamlit/secrets.toml`（**已被 .gitignore 排除**）
- 云端：Advanced settings → Secrets 粘贴同样内容，**不会写进 git**
- 我们的 `utils/llm.py` 直接读 `os.environ`——Community Cloud 会把 secrets 注入为环境变量，所以**不用改代码**就能读到
- secrets.toml 格式：

```toml
LLM_PROVIDER = "stepfun"
HERMES_CUSTOM_STEPFUN_API_KEY = "sk-..."
```

> ⚠️ 部署时先建一个 **测试专用的小额 key**，不要把自己的主 key 贴到云端。

## 5. 上线前检查清单

- [ ] 本地 `streamlit run app.py` 打开一次，确认界面正常（已有 AppTest 冒烟测试兜底）
- [ ] `.streamlit/secrets.toml` 已建且 **git status 确认它不被提交**
- [ ] `requirements.txt` 在 app.py 同目录
- [ ] 云端 Python version = 3.11
- [ ] 部署后访问线上 URL，跑一遍"粘贴文本 → 摘要"全流程
- [ ] 把线上 URL 写进 `docs/简历骨架.md` 作品集栏 + README

## 6. 上线后的运营（面试素材）

- 把线上 URL 发给 2-3 个同学/同门试用，收 3 条真实反馈 → log 记录
- 看有没有人真的用：Streamlit Cloud 有 app 访问统计，截图存证
- 复盘："上线后我发现 __，于是修了 __"——真实上线数据比任何 demo 都有说服力

## 7. 风险与止损

| 风险 | 应对 |
|---|---|
| 云端 Python 3.12 与本地 3.11 行为差异 | Advanced settings 强制选 3.11 |
| 密钥泄露 | 用测试专用 key；secrets 不进仓库；部署后可从后台撤销 |
| 免费额度限制 | L1 低频使用没问题；真超限再说 |
| app 无人访问 | 主动发给同学试用，收集反馈本身就是运营 |
