# L2 案例① 项目说明：个人知识库问答（一页版）

> 写完日期：2026-10-15（Day 23）· 对应面试"能讲 15 分钟的案例①"
> 原则：每个数字都指向 `projects/L2-knowledge-base/logs/*.json` 的真实产物，不手写数字。

---

## 一句话

**把你自己的一堆资料（文档/日志/笔记）变成一个可以问答的知识库：自然语言提问，答案带精确引用（可点到原文段落），答不出的明确说"资料里没有"。**

## 解决谁的什么问题

研究生/职场新人查自己的资料：全文搜索只能命中关键词（"那个关于迁移成本的说法"搜不到）、翻半小时找不到一句话、用 AI 聊又怕它编。核心场景：**① 我记得看过这个，在哪？② 这几份资料里关于 X 怎么说？③ 我要写东西，需要准确引用。**

## 为什么必须用 AI（面试必答）

1. **关键词检索命中率低**：资料非结构化，"迁移成本"这种问法只有语义检索能命中。
2. **引用可信度必须靠模型判断**：哪一段真正回答了问题，规则判不了。
3. **"答不出就说不知道"需要模型自评**：证据不足要主动拒答，这依赖模型判断。
> ⚠️ 反面案例（会被打回）：只把所有资料喂长上下文模型 = 没有检索环节，讲不出检索质量指标。

## 方案与取舍（面试重点）

| 层 | 选择 | 为什么 / 为什么不选另一种 |
|---|---|---|
| 检索 1 | **混合检索**（稠密向量 + 中文二元组 BM25 → RRF 候选池） | 纯稠密实测 Recall@5 = 0%（nemotron 中文弱，ASCII 图块污染）；二元组让图块零 token 天然免疫 |
| 检索 2 | **Rerank 精排**（bce-reranker-base_v1 本地 cross-encoder） | RRF 是"排名信任"，日志块在双榜霸榜时无解；精排直接判 (问,块) 语义相关。**P@5 38%→55%、MRR 0.585→0.713、引用准确率 80%→100%** |
| 分块 | 标题层级切段 + 512 字句子窗口（64 重叠），**每块记录原文偏移** | 引用能精确高亮到原文段落（面试验证点）；硬不变量有单测（块文本==原文切片） |
| 生成 | 复用 L1 故障转移端点表 + quote 连续子串校验 | 引用必须逐字可定位，改写/拼接全拒 |
| 拒答 | 检索词面把关 + 模型 unanswerable | "资料里没有"不许硬答；10 条无答案问题评测 100% |
| 存储 | Chroma + sha1 指纹同步 | 数据量小用轻量库（vs FAISS：需元数据过滤/持久化） |
| 评估 | 4 指标：召回/上下文相关性(P@5)/引用准确率/拒答 | 30 条正式评测集（20 有答案 + 10 无答案），gold 有自校验 |

## 效果（真实评测数字，`logs/qa_eval_w4.json` + `logs/retrieval_eval_w3.json`）

| 指标 | 数字 | 目标 | 说明 |
|---|---|---|---|
| 召回率 Recall@5 | **100%**（20/20） | ≥90% | Rerank 后从 90%→100% |
| 上下文相关性 P@5 | **55%** | ≥60% | RRF 38% → Rerank 55%；差 5pp（同义改写题/命令题，见下） |
| 引用准确率 | **100%**（20/20） | ≥95% | Rerank 后 80%→100% |
| 拒答正确率 | **100%**（10/10） | ≥90% | 无答案问题全拒 |
| MRR | 0.713 | — | —
| 单测 | 44 个 | — | 离线不花 API |

**口径（诚实）**：gold_status = draft_manual（我自己标的，9 题补录过）；引用准确率 100% 是修正 gold 后口径；上下文相关性 55% 是最大短板，差 5pp 到目标。

## 踩坑（失败怎么排查的——证据链）

1. **上下文相关性 30%（Day21 发现）≠ 检索没召回** → 90% 能召回但 top-5 里 3.5 块是噪声 → 先试扩池/RRF 权重/doc 聚合（排名型天花板 ≈45%）→ 才上 cross-encoder 精排（55%）
2. **Chroma 两次独立 get 顺序不稳** → 文本/元数据错位、偶发漏检 → 一次 get(include=两者) + 回归测试
3. **索引过期**（语料天天变）→ 症状像随机 bug，实为 in_sync=false → --check 纪律
4. **gold 标窄冤枉系统**（评测 60%→90%）→ gold 是"合理来源候选集"不是唯一文档 → 校验器内置
5. **模型/库坑**：fastembed 砍了 rerank 模块 → 换 FlagEmbedding；hf.co 被墙 → hf-mirror + 断点续传（760MB 截断无妨，1.11GB 完整即加载成功）
