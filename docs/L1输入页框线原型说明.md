# L1 项目「输入页」框线原型说明（Day 1 · Figma 练习）

> 目标：在 Figma 里画 **1 页框线原型**（wireframe），练习结束。
> 画的对象：L1 项目（长文 → 结构化）的**输入页**。
> 建议画法：用 Figma 的 Frame（尺寸 1440×900）+ Rectangle/Text 画框线，**不用真实内容**，全部用灰色方块和占位字。

---

## 页面布局（从上到下）

```
┌──────────────────────────────────────────────┐
│ 标题区                                        │
│   长文结构化助手                               │  ← 大标题（36px 粗体）
│   粘贴或上传一篇文章，30 秒出摘要/要点/待办      │  ← 副标题（16px 灰）
├──────────────────────────────────────────────┤
│ 输入区（卡片，白底带边框）                      │
│   ┌──────┬──────┬──────┐                     │
│   │ 粘贴文本 │ 链接抓取 │ PDF 上传 │            │  ← Tab 切换（3 个）
│   └──────┴──────┴──────┘                     │
│   ┌──────────────────────────────────────┐   │
│   │ 在这里粘贴长文…（占位文字，灰）            │   │  ← Textarea（高约 200px）
│   └──────────────────────────────────────┘   │
│                                              │
│   输出模板： (•) 摘要  ( ) 待办  ( ) 归档      │   ← Radio 单选，默认"摘要"
│                                              │
│   ┌────────────────────┐                     │
│   │      一键结构化      │                     │  ← 主按钮（蓝色填充）
│   └────────────────────┘                     │
├──────────────────────────────────────────────┤
│ 结果区（灰显占位，提示"结果将显示在这里"）        │  ← 虚线边框的占位框
│   ┌──────────────────────────────────────┐   │
│   │ 摘要卡片 / 关键点列表 / 标签 / 待办       │   │
│   └──────────────────────────────────────┘   │
└──────────────────────────────────────────────┘
```

## 要画出的元素清单

| # | 元素 | 用什么画 | 说明 |
|---|---|---|---|
| 1 | 页面 Frame | Frame，1440×900 | 整页容器 |
| 2 | 标题 + 副标题 | Text | 36px 粗体 / 16px 灰 |
| 3 | 输入卡片 | Rectangle + 边框 | 圆角 8px |
| 4 | 三个 Tab | 3 个 Rectangle + Text | 第一个高亮（蓝色底线或填充） |
| 5 | 粘贴区 | 大 Rectangle | 高 200px，内部灰字占位 |
| 6 | 模板单选 | 3 个 Radio（圆形 + 文字） | 默认选中"摘要" |
| 7 | 主按钮 | Rectangle 蓝色 + Text | 居中 |
| 8 | 结果占位区 | 虚线 Rectangle | 内部灰字："结果将显示在这里" |

## 练习完成标准

- [ ] 8 个元素都画出来了
- [ ] 元素对齐（用 Figma 的自动对齐参考线）
- [ ] 导出为 PNG 保存到 `projects/` 或 `log/` 目录

## 为什么要画这个

1. **练 Figma 基本操作**：Frame / Rectangle / Text / 对齐 / 图层命名
2. **产品思维训练**：输入页要解决"用户怎么把内容交给 AI"——三个 Tab 就是三种输入方式的取舍
3. **作品集素材**：这张框线 + 后面的高保真稿，就是 PRD 的配图

> 面试能讲：**"我设计了三种输入方式（粘贴/链接/PDF），因为访谈发现用户来源场景不同——链接抓取失败率超过 40% 时我直接砍掉了它，只留粘贴和上传。"**（取舍 + 数字）
