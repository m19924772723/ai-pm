## 四类失败（按链路环节）

### ① 检索漏召回（同义改写题）——真短板，W4 优化
- **例**："L1 用了哪个界面框架？" → 正确块（技术选型草稿 #38，含"前端/UI Streamlit"）
  dense_rank=89、lex_rank=192，都没进 top-5
- **根因**：问题说"界面框架"，原文写"前端/UI"——词面不重叠，embedding（中文弱）也认不出。
  混合检索只能救"词面命中"，救不了"同义改述"
- **对策（W4）**：查询改写（同义词扩展）或换更强中文 embedding（本地 BGE）

### ② 生成阶段误拒答（LLM 保守）——已修一半，剩 3 条
- **现象**：GOLD 块明明在检索 top-5 里，LLM 却输出 unanswerable=true
- **根因**：prompt 规则 4 原文"无法直接回答就拒答"→ LLM 对"需从表格读数字/需概括"的题
  一律拒答。**宁可不答也不猜**是安全习惯，但对 RAG 过度
- **修复**：规则 4 改为"只有完全无关才拒答；间接包含答案（同主题/表格/概括）应作答"
- **效果**：单改 prompt 就把引用准确率从 45% → 65%（v4 原生值）
- **剩余 3 条**："评测集多少条"（需读表格数字）、"Chroma vs FAISS 优缺点"、"满意度几分"——
  检索 top-5 有相关块但 LLM 仍拒/引错，可能是 prompt 还不够强或 LLM 端波动 → W4 复查

### ③ gold 标注问题（评测集自身）——已基本修完
- 共修 8 条 gold：操作题补 README、事实/决策题补 log 来源、Day 5 补 README
- **教训**：评测集 gold 是"合理来源候选集合"，不是"唯一正确文档"；
  同一内容散在多处（docs/log/README），只标一处会冤枉系统（Day 18 也踩过）
- gold 校验器（`build_qa_evalset.py` 内置）保证每个前缀真在语料里，防标空

### ④ 端到端环境问题——已修
- **全端点瞬态失败中断评测**（v3 首跑 20/30 处 exit=1）→ `_answer_with_retry` 捕获 QAError 重试 3 次
- 4 端点全部短时不可用出现过 2 次（stepfun/deepseek/tuoji 轮流抽风）→ 故障转移是必需
