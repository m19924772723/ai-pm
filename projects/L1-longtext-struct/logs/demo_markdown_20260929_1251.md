# 产品经理，你真的理解俞军的产品价值公式吗？

> 本文解读俞军产品价值公式，拆解体验差、迁移成本、相对价值等核心逻辑，指导产品经理在存量市场竞争中取胜。

## 关键点

- **产品价值公式为（新体验-旧体验）-迁移成本，凝练产品竞争本质**
  - 依据：产品价值 = （新体验 – 旧体验）- 迁移成本 产品价值公式凝练了产品竞争的本质。
- **当前移动互联网处于存量市场，移动网民规模稳定在11.3亿**
  - 依据：当下是移动互联网的下半场，在用户量层面将长期处在存量市场（移动网民稳定在11.3 亿）。
- **体验差由新旧体验对比产生，大于迁移成本时用户会迁移至新产品**
  - 依据：当体验差大于用户的迁移成本时，用户就会做出使用新产品的决定。
- **可通过打造核心特性、外部推广降低迁移成本，也可通过数据沉淀增加迁移成本**
  - 依据：打造产品内在动力和综合运用外部刺激是常用的两种降低迁移成本的手段。
- **产品价值是相对价值，需放大核心优势与附加价值以获取竞争优势**
  - 依据：产品价值公式里的价值是相对价值，是相比较于其他产品的亮点、优势、额外的价值。
