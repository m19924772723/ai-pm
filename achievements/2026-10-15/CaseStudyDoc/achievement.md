# CaseStudyDoc（案例①项目说明 + 试用材料）

**成果词**：CaseStudyDoc —— 首个作品集案例从"技术完成"到"可交付、可讲、可试用"

## 做成了什么

| 项 | 结果 |
|---|---|
| 项目说明 | `docs/L2-1项目说明.md`：一页面试版（对齐 L1 模板：一句话/解决谁/为什么 AI/取舍/效果/踩坑/谁在用/我负责的部分） |
| 数字 | 全部指向 logs/*.json：召回 100% / P@5 55% / 引用 100% / 拒答 100% / MRR 0.713 |
| 取舍表 | 混合检索→Rerank 演进（38%→55%）、分块偏移、Chroma vs FAISS、4 指标——面试重点 |
| 踩坑链 | 5 条证据链（30% 排查→Rerank、Chroma get、索引过期、gold、模型/库坑） |
| 试用材料 | `docs/L2-1试用材料.md`：邀请话术 + 演示流程 + 反馈模板 + 阈值 |

## 为什么这件事重要

L2 从"代码+数字都齐"（Day 22）到"能讲 15 分钟 + 能找真人试用"（Day 23）：
- **项目说明 = 面试弹药**：数字和取舍都是可复现的（logs json + 单测 44）
- **试用材料 = 上线前哨**：真实反馈能转成评测集新 gold（gold 从 draft 转 reviewed 的输入）
- 诚实口径写进文档（gold 草案、55% 差 5pp）——面试官追问时有底
